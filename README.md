# Portfolio — Samy Bensassi

Portfolio V1 en HTML/CSS/JavaScript, responsive PC/mobile.

## Fichiers
- `index.html` : contenu du site
- `style.css` : design
- `script.js` : menu mobile + animations
- `README.md` : ce fichier

## À modifier en priorité

### 1. E-mail
Dans `index.html`, remplace :
`ton-email@example.com`

### 2. CV
Ajoute ton CV PDF dans le dossier, par exemple :
`CV_Samy_Bensassi.pdf`

Puis remplace le bouton :
```html
<a class="btn btn-secondary disabled" href="#" aria-disabled="true">CV à ajouter</a>
```
par :
```html
<a class="btn btn-secondary" href="CV_Samy_Bensassi.pdf" target="_blank">Voir mon CV</a>
```

### 3. Projets BTS
Remplace les trois cartes "À compléter" par tes vrais projets.
Pour chaque projet, ajoute :
- Contexte
- Objectif
- Technologies utilisées
- Ce que TU as fait
- Difficultés rencontrées
- Résultat
- Compétences BTS / E5 associées
- Captures d'écran anonymisées si besoin

### 4. Veille technologique
Choisis un vrai thème de veille et ajoute :
- Sujet
- Pourquoi ce sujet
- Outils / sources de veille
- 3 à 5 actualités ou évolutions
- Synthèse personnelle

## Hébergement gratuit avec GitHub Pages
1. Crée un compte GitHub si besoin.
2. Crée un dépôt public, ex. `portfolio-samy`.
3. Envoie tous les fichiers du dossier.
4. Va dans Settings > Pages.
5. Source : Deploy from a branch.
6. Branche : `main` / dossier `/root`.
7. GitHub fournira une URL publique.

## Conseil BTS
Évite d'inventer des compétences ou projets. Le portfolio doit être cohérent avec tes preuves, captures et réalisations réelles.
